# 听课台还原：公用布局骨架

这是还原系列的基础层，不是逐页视觉验收完成，也不改变业务数据。

## 层级与契约

- `ListenDeskShell` 是唯一学习者壳：品牌 / 出处搜索 / PC 顶栏导航、内容舞台、手机底栏。禁止另起一套中台侧栏壳。
- `DeskStage` 管宽度、居中、内边距和间距。`narrow` 为首页、搜索、收获匣、回想（640px）；`default` 为系列及分集（720px）；`watch` 为学一段（800px）；`tool` 为图谱、路径（铺满壳，保留原有内容布局）。PC 媒体查询只改内边距，不覆盖变体宽度。
- `WatchFrame` 管上固定槽 `fixed`（返回导航和真实播放器）、固定文稿/章切换 `tabs`、唯一列表滚动槽 `children`，以及独立浮层 `overlays`。文稿定位 ref 始终交给 `.script-scroll`。
- 学一段所有宽度都纵向堆叠，播放器在上、转写在下；不能恢复 1024px 的左右分栏或 38% 播放器宽度。
- watch 高度链为 `100vh` 回退 / `100dvh` 优先，壳、main、stage、script-section 均 overflow hidden，只有 script-scroll（文稿或章节）overflow-y auto。手机底栏作为定高壳最后一个 flex 子项钉在底部，PC 隐藏底栏。
- `styles.css` 的 `--desk-*` 提供听课台独立尺度，骨架不依赖 `--sidebar-w` / `--panel-w`。现有色板仍是候选 A，尤其 #3370FF 未拍板；这里不升级为品牌硬规范。
- 不模拟本站音频、不恢复写死进度。YouTube 仍需主动打开，“请求定位”不声称实时播放同步。

## 验证

`cd web && npm test`；`npm run build`。

`deskSkeleton.test.tsx` 先 RED 再 GREEN：真实页面 SSR 验证组件接入，CSS 源契约检查所有媒体查询中的同选择器声明，防止 PC 覆盖悄悄恢复 row / 38%。不用 jsdom 的 computed style 冒充真实布局引擎。源契约不代替浏览器视觉验收。

## 后续逐页修复与合并门槛

- 首页主卡、标题与主按钮的视觉比例；系列封面及卡片、分集列表的细节。
- 学一段播放器形态、大标题、转写层级及短屏可读性；不牺牲真实播放器与定位诚实度。
- 搜索、收获匣、回想的密度、空态与长文案；图谱 / 路径的密排和业务文案不在此改。
- 顶栏导航是否收敛另议；本次只保证 PC 搜索最小可读宽度。
- 合并前需真实浏览器核对至少 1920×1080、1280×800、390×844 和手机横屏：单列、文稿/章节独立滚动、顶栏/播放器不动、底栏不遮挡、搜索 placeholder 完整。还需真机 iOS/Android 地址栏与安全区检查，以及主动打开 YouTube 后的布局检查。
- 本分支不合 main、不部署；按页后续修复应另行测试。
